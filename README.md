## 一、第一次用：先把后端建起来（只做一次）

网站现在能在线写信、传照片了，内容存在你们自己的 Supabase 里。
数据库还空着，需要跑一次建库脚本：

1. 打开 **https://supabase.com/dashboard** → 选中 `2400016611's Project`
2. 左边点 **SQL Editor** → **New query**
3. 把项目里 `supabase/setup.sql` 这个文件**整份复制**进去，粘贴，点 **Run**
4. 往下看「二、谁能进来看」那一段，**把两个邮箱改成你们俩注册时要用的邮箱** —— 这一步别跳过，
   只有名单里的邮箱登录进来才看得到东西

跑完回到 https://2400016611.github.io/write.html 刷新，右上角就能登录了。

### 然后注册你们两个的账号

点右上角「登录」→「第一次来 · 注册」，用自己的邮箱和密码注册（密码至少 6 位）。

注册后可能会收到一封确认邮件，点一下里面的链接再回来登录。
**收不到邮件或懒得折腾**，可以在 Supabase 后台做两件事之一：

- **Authentication → Users** 里能看到这个用户，点右边的 `…` → 直接确认（Confirm email）
- 或者 **Authentication → Sign In / Providers → Email**，把 **Confirm email** 关掉，之后注册就免确认

顺手建议把 **Authentication → URL Configuration → Site URL** 改成
`https://2400016611.github.io/`，这样确认邮件里的链接会跳回你们的站，而不是 localhost。

> 登录之后看到一片空白，只有一条「不在成员名单里」的提醒？
> 说明这个邮箱没加进前面那份名单。在 SQL Editor 里跑一句就行：
> ```sql
> insert into public.members (email) values ('你的邮箱');
> ```

## 二、平时怎么用

| 想做什么 | 去哪 |
|---|---|
| 写一封信、夹照片 | 右上角「写一封信」→ 写一封信 |
| 随手记一句（两个人都看得到） | 首页「写一句」，或「写一封信」→ 碎碎念 |
| 传照片、传视频 | 照片墙 →「传照片 / 视频」 |
| 点亮「这一年」上的某一天 | 「写一封信」→ 这一年 |
| 加生日、周年这种每年都会回来的日子 | 「写一封信」→ 这一年 → 纪念日 |
| 改在一起的日子、距离、下次见面 | 「写一封信」→ 设置 |
| 收藏一张喜欢的 | 点开大图 → 收藏；照片墙上会多一个「最喜欢」 |
| 让别人也能看某一封 | 写信时勾上「别人也能看这一封」 |

没登录的人打开网站，看到的是**最早那一版的内容**（`data/content.js` 里那份），
以及你们勾了「别人也能看」的信和照片。你们自己的私房内容只有登录后看得见。

## 三、改了内容怎么更新线上

在网页上写的东西**立刻就在线上**，不用做任何事。
只有改了代码/样式/静态内容才需要发布：

```
cd site
git add -A
git commit -m "更新"
git push
```

push 后等一两分钟，刷新网页就能看到。

## 四、本地怎么看

双击 `index.html` 也能看，但**建议起一个小服务**，因为浏览器对 `file://` 的限制会让登录用不了：

```
cd site
python -m http.server 8000
```

然后浏览器打开 http://localhost:8000

supabase/seed.sql          把现有内容搬进数据库
tools/make_seed_sql.mjs    重新生成上面两个 seed 文件
```

## 六、想加照片和视频（走仓库这条老路）

网页上传适合随手加几张。要一次加很多、或者要转码，还是走本地这条：

1. 把文件丢进上一层的 `materials/photos/` 或 `materials/videos/`
2. 在项目根目录跑一次：

```
python tools/build_media.py
```

照片会自动压成网页大图和缩略图；视频转成浏览器能放的 H.264，并抽出首帧当封面。
新照片按文件名顺序编号（p54、p55……），之后跑一次 `node tools/make_seed_sql.mjs`
并把 `supabase/seed.sql` 贴进 Supabase，数据库里才会有它们。

**注意**：视频原样上传会很大（1 分钟 1080p 大约 60–200 MB），
Supabase 免费额度是 1 GB 存储 / 5 GB 月流量。传之前最好先剪短、压到 720p。

## 七、出问题了先看这几条

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 页面顶上有一条「后端还没建好」 | `setup.sql` 还没跑 | 做上面第一节 |
| 登录了但什么都看不到 | 邮箱不在 `members` 名单里 | 跑 `insert into public.members (email) values ('你的邮箱');` |
| 注册后登录不了 | 邮箱没确认 | 后台 Users 里手动确认，或关掉 Confirm email |
| 传视频传到一半失败 | 视频太大 | 先在手机/电脑上压一下再传 |
| 显示的还是老内容 | 后端连不上，自动退回静态内容 | 刷新；还不行就去 Supabase 看看项目是不是被暂停了（免费项目闲置会暂停）|
